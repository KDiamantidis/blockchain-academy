Καλώς ήρθες στον κόσμο του Web Security! Αν φτάνεις εδώ χωρίς προηγούμενη εμπειρία, μην ανησυχείς, αυτός ο οδηγός έχει σχεδιαστεί ειδικά για εσένα. Θα ξεκινήσουμε από τα απολύτως βασικά και θα προχωρήσουμε βήμα-βήμα.

## 1.1 Τι είναι το Web Security;

Το **Web Security** (ή αλλιώς Ασφάλεια Διαδικτύου) είναι ο τομέας που ασχολείται με την προστασία των ιστοτόπων, των εφαρμογών και των δεδομένων από κακόβουλες επιθέσεις.

Φαντάσου έναν ιστότοπο σαν ένα σπίτι: το Web Security είναι το σύστημα ασφαλείας που κλειδώνει τις πόρτες, παρακολουθεί τα παράθυρα και αποτρέπει τους κλέφτες.

Κάθε φορά που χρησιμοποιείς μία εφαρμογή, είτε κάνεις online αγορές, είτε ελέγχεις email, είτε συνδέεσαι σε social media, αλληλεπιδράς με συστήματα που έχουν πιθανά κενά ασφαλείας. Ο στόχος του Web Security είναι να εντοπίζει και να διορθώνει αυτά τα κενά πριν τα εκμεταλλευτεί κάποιος με κακές προθέσεις.

Στην ομάδα μας ασχολούμαστε με το Web Security και ιδιαίτερα με το **Web Exploitation**, δηλαδή την εύρεση και την εκμετάλλευση ευπαθειών σε web εφαρμογές. Μια **ευπάθεια** (vulnerability) είναι ένα σφάλμα στον σχεδιασμό ή στον κώδικα που επιτρέπει σε κάποιον να κάνει κάτι που ο developer δεν είχε προβλέψει, και το **exploit** είναι η ενέργεια που την εκμεταλλεύεται. Για να τις βρίσκεις και να τις διορθώνεις, πρέπει να καταλαβαίνεις πώς σκέφτεται ένας επιτιθέμενος. Αυτό το κάνουμε πάντα σε εξουσιοδοτημένα περιβάλλοντα.

## 1.2 Τι είναι το Ethical Hacking;

Ο όρος "hacking" έχει αποκτήσει αρνητική σημασία στα μέσα ενημέρωσης, αλλά στην πραγματικότητα υπάρχουν διαφορετικοί τύποι hackers:

- **White Hat Hackers (Ηθικοί Hackers):** Είναι επαγγελματίες που με άδεια του ιδιοκτήτη εντοπίζουν αδυναμίες σε συστήματα για να βοηθήσουν στην ασφάλεια.
- **Black Hat Hackers:** Κακόβουλοι hackers που εισβάλλουν σε συστήματα χωρίς άδεια για προσωπικό κέρδος ή βλάβη.
- **Grey Hat Hackers:** Βρίσκονται στη μέση, μπορεί να εισβάλλουν χωρίς άδεια αλλά χωρίς κακές προθέσεις, ενδεχομένως για να ενημερώσουν τον ιδιοκτήτη.

Το **Ethical Hacking** (ή Penetration Testing / Pen Testing) είναι η πρακτική να δοκιμάζεις συστήματα με τη ρητή άδεια του ιδιοκτήτη, για να εντοπίσεις ευπάθειες πριν τις ανακαλύψουν οι κακόβουλοι. Είναι νόμιμο, ηθικό και εξαιρετικά περιζήτητο στην αγορά εργασίας.

## 1.3 Γιατί είναι σημαντικό το Web Security;

Τα στατιστικά είναι εντυπωσιακά: κάθε μέρα γίνονται εκατοντάδες χιλιάδες κυβερνοεπιθέσεις παγκοσμίως. Μια επιτυχημένη επίθεση μπορεί να οδηγήσει σε:

- Κλοπή προσωπικών δεδομένων (ονόματα, κωδικοί, αριθμοί καρτών)
- Οικονομική ζημιά σε επιχειρήσεις και χρήστες
- Διακοπή υπηρεσιών (websites, εφαρμογές)
- Ζημιά στη φήμη οργανισμών
- Διαρροή εμπιστευτικών επαγγελματικών πληροφοριών

## 1.4 Νομικό & ηθικό πλαίσιο

<p class="warn"><strong>Πολύ σημαντικό:</strong> Πριν προχωρήσεις στο υλικό αυτό, πρέπει να κατανοήσεις το εξής: η δοκιμή ασφαλείας σε συστήματα χωρίς ρητή άδεια του ιδιοκτήτη είναι <strong>παράνομη</strong>.</p>

> **Χρυσός κανόνας:** Δοκίμαζε ΜΟΝΟ σε δικά σου συστήματα, σε ειδικά εκπαιδευτικά περιβάλλοντα (labs), ή με γραπτή άδεια. Ποτέ σε συστήματα τρίτων χωρίς άδεια.

Υπάρχουν πολλά νόμιμα εκπαιδευτικά περιβάλλοντα όπου μπορείς να εξασκηθείς με ασφάλεια, όπως το PortSwigger, το HackTheBox, το TryHackMe και το WebGoat (θα τα αναφέρουμε αργότερα).

## 1.5 Πώς να αξιοποιήσεις αυτόν τον οδηγό

Συνιστούμε:

1. Διάβασε κάθε κεφάλαιο με τη σειρά, κάθε ένα χτίζει πάνω στο προηγούμενο.
2. Ψάξε παραπάνω όρους που δεν καταλαβαίνεις ή ζήτα βοήθεια.

## Σύνοψη

- Το Web Security προστατεύει ιστοτόπους και εφαρμογές από επιθέσεις.
- Το Ethical Hacking είναι νόμιμη δοκιμή συστημάτων με άδεια του ιδιοκτήτη.
- Υπάρχουν White Hat (ηθικοί), Black Hat (κακόβουλοι) και Grey Hat hackers.
- Η δοκιμή χωρίς άδεια είναι παράνομη, πάντα να εξασκείσαι σε εξουσιοδοτημένα περιβάλλοντα.
