Τώρα που καταλαβαίνεις πώς επικοινωνεί ο ιστός, ας εξετάσουμε τις τεχνολογίες που χτίζουν τις εφαρμογές. Αυτές είναι τα "δομικά υλικά" κάθε ιστοτόπου.

## 3.1 HTML, η δομή

Το **HTML** (HyperText Markup Language) είναι η γλώσσα που ορίζει τη δομή μιας ιστοσελίδας. Σκέψου το σαν τον σκελετό ενός κτηρίου. Το HTML χρησιμοποιεί «ετικέτες» (tags) για να ορίσει στοιχεία:

```html
<h1>Τίτλος Σελίδας</h1>
<p>Αυτό είναι μια παράγραφος κειμένου.</p>
<a href="https://example.com">Σύνδεσμος</a>
<input type="text" name="username">
<form action="/login" method="POST">...</form>
```

Από σκοπιά ασφαλείας, το HTML είναι ιδιαίτερα σημαντικό γιατί:

- Τα forms (φόρμες) είναι το κύριο σημείο εισόδου δεδομένων από χρήστες.
- Η tag `<a>` μπορεί να κατευθύνει χρήστες σε κακόβουλες σελίδες.
- Η εισαγωγή HTML κώδικα από χρήστη (HTML Injection) είναι κοινή ευπάθεια.

## 3.2 JavaScript, η λογική

Η **JavaScript** (JS) είναι η γλώσσα προγραμματισμού που κάνει τις σελίδες διαδραστικές. Αν το HTML είναι ο σκελετός, η JS είναι οι μύες.

Η JavaScript εκτελείται στον browser του χρήστη (client-side). Αυτό έχει σημαντικές συνέπειες για την ασφάλεια:

- Όλος ο κώδικας JS που κατεβαίνει στον browser είναι ορατός στον χρήστη.
- Ένας κακόβουλος χρήστης μπορεί να τροποποιήσει τη συμπεριφορά της εφαρμογής.
- Η JS μπορεί να χρησιμοποιηθεί για επιθέσεις XSS (θα δούμε στο Κεφάλαιο 7).

Παράδειγμα κώδικα JavaScript:

```js
// Αυτός ο κώδικας εκτελείται στον browser
function validateForm() {
  var username = document.getElementById('user').value;
  if (username === '') {
    alert('Παρακαλώ εισάγετε username');
    return false;
  }
}
```

<p class="warn"><strong>Σημαντικό:</strong> Η επικύρωση δεδομένων μόνο σε JavaScript (client-side) είναι επικίνδυνη! Ένας hacker μπορεί εύκολα να παρακάμψει αυτόν τον έλεγχο και να στείλει απευθείας αιτήματα στον server χωρίς να περάσει από το form. Πάντα πρέπει να γίνεται επικύρωση και στον server.</p>

## 3.3 CSS, η εμφάνιση

Το **CSS** (Cascading Style Sheets) ελέγχει την εμφάνιση της σελίδας, δηλαδή χρώματα, γραμματοσειρές, διάταξη. Από σκοπιά ασφαλείας, το CSS έχει μικρότερο ρόλο, αλλά μπορεί να χρησιμοποιηθεί για επιθέσεις κρυφής εμφάνισης στοιχείων ή clickjacking.

## 3.4 Πώς λειτουργεί ο browser

Ο browser είναι ένα εξαιρετικά πολύπλοκο πρόγραμμα. Όταν επισκέπτεσαι μια σελίδα:

1. Κατεβάζει το HTML αρχείο από τον server.
2. Αναλύει (parse) το HTML και δημιουργεί το DOM (Document Object Model).
3. Κατεβάζει επιπλέον αρχεία: CSS, JavaScript, εικόνες.
4. Εκτελεί τη JavaScript.
5. Εμφανίζει τη σελίδα στην οθόνη.

> **DOM:** Η εσωτερική αναπαράσταση της σελίδας ως δέντρο αντικειμένων. Η JavaScript μπορεί να τροποποιήσει το DOM για να αλλάξει τη σελίδα δυναμικά.

## 3.5 Αρχιτεκτονική web εφαρμογών

Οι σύγχρονες web εφαρμογές αποτελούνται συνήθως από:

- **Frontend:** Ό,τι τρέχει στον browser του χρήστη (HTML, CSS, JS). Ορατό σε όλους.
- **Backend:** Ο κώδικας που τρέχει στον server (π.χ. Python, PHP, Node.js, Java). Δεν είναι ορατός στον χρήστη.
- **Database:** Εδώ αποθηκεύονται τα δεδομένα (χρήστες, προϊόντα κ.λπ.). Π.χ. MySQL, PostgreSQL, MongoDB.
- **API:** Ένα σύνολο κανόνων για επικοινωνία μεταξύ frontend και backend.

> Η ασφάλεια πρέπει να εφαρμόζεται σε όλα τα επίπεδα! Η ασφάλεια μόνο στο frontend είναι ανεπαρκής.

## Σύνοψη

- Το HTML ορίζει τη δομή, το CSS την εμφάνιση και η JavaScript τη λογική μιας σελίδας.
- Ο κώδικας JavaScript είναι ορατός στον χρήστη και δεν πρέπει να περιέχει ευαίσθητα δεδομένα.
- Η αρχιτεκτονική διαδικτυακών εφαρμογών περιλαμβάνει frontend, backend και database.
